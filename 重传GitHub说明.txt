【先看效果】
1. 解压到任意目录
2. 双击「启动本地站点.bat」，会自动起本地服务并打开 http://127.0.0.1:8769/
   （需要 Python 3；脚本先找 PATH 里的 python，找不到会提示安装）
3. 不要直接双击 app/index.html —— file:// 方式读不到 library.json 和模型，必须走本地 HTTP 服务

【重新上传到 GitHub（想恢复原地址的话）】
1. 用 haqzo 账号新建 public 仓库，名字必须还是 Rom-Patch-Manager，否则 Pages 地址会变
2. 解压后在该目录执行：
     git init
     git add -A
     git commit -m "restore Rom-Patch-Manager 1.1.4 (source snapshot)"
     git branch -M main
     git remote add origin https://github.com/haqzo/Rom-Patch-Manager.git
     git push -u origin main
3. 仓库 Settings → Pages → Build and deployment → Source 选择 GitHub Actions
4. 推送后 Actions 会自动跑 test + deploy（部署时会用 scripts/add-community.mjs 重建库索引），
   绿灯后 https://haqzo.github.io/Rom-Patch-Manager/ 即恢复
