# Experiments — files to try

Test files that are **not** part of the website. One folder per idea: `experiments/<topic>/` with the files and a
`README.md` (what it is, how to try it, and the result once Haqzo or MaToRiuKo tested it in PokeMMO).

- Models must go through CTRMap-CE to become `.nsbmd` (see docs/HANDOFF-CHATGPT.md §5).
- No ROMs, ROM dumps or patched ROMs here.
- When something works in game, move it to `library-src/community/` in a pull request.
